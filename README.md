# M5-Demand-Forecasting-Powerbi
End-to-end demand forecasting &amp; inventory optimisation using Walmart M5 data, Python (Prophet/XGBoost), and Power BI

## Overview

This project builds a demand forecasting and inventory optimisation solution for retail supply chain management. It uses real-world Walmart sales data to forecast product demand, calculate optimal inventory levels, and surface replenishment recommendations through an interactive Power BI dashboard.

Built as a portfolio project targeting roles in supply chain analytics, demand planning, and inventory management.

## Tools & Technologies

- Python — data cleaning, EDA, forecasting model (Prophet / XGBoost)
- Power BI — interactive dashboard (5 pages)

## Dataset

This project uses the M5 Forecasting dataset (Walmart retail sales data).

Download it from Kaggle: https://www.kaggle.com/c/m5-forecasting-accuracy/data

Once downloaded, place the files in a `/data` folder in the project root:

The data files are excluded from this repo per Kaggle's competition terms.
